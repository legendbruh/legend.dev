EXAMPLE:

A 3D planet sits in the center.

- Drag → rotate planet
- Scroll → zoom camera
- Mouse → changes lighting
- Click → planet information appears
- Hover → text floats around it
- Double-click → secret mode
- Keyboard → changes planet
- Background → reacts to planet
- Particles → orbit planet
- Audio → changes with interaction
- Mobile → swipe to rotate
- Search → finds related content
